# Pass 02 selection layout

The selection screens share a measured layout. An unplaced reference composition measures the localized Tenses options at the current width and font scale. The preferred action centre is halfway from the last tense card to the safe content bottom. The shared app-bar height measurement compensates for differently wrapped screen titles. Later screens use that position when they fit; longer content moves the action down, with 16 dp clearance. A bounded scroll viewport keeps the action accessible on constrained screens. The reference uses the same clearance and bottom clamping as Tenses, including its scrolling threshold. In multi-column layouts the reference uses the bottom of the entire final option row; individual cards retain their natural height so wrapped text is never squeezed by intrinsic-height rounding.

Important verbs and regular -er categories show All only when at least one visible choice is unselected. The existing Selection model remains authoritative, including the conditional future category. Families have individual selection only, retain their three groups and use a heading plus member list. Category examples and localized explanations share one wrapping secondary text block. Selection cards retain 60 dp minimum targets and 30 dp selection ticks.

Regression coverage is in SelectionRefinementTest, VerbFlowTest and VerbLayoutTest. It includes All/manual selection, conditional future availability, rotation/recreation, midpoint and cross-screen alignment, safe bounds, text wrapping and reachability. The full product matrix has 1,008 cases, including 420 selection cases; the inherited About matrix has 140 cases. Actual emulator captures supplement the simulated dimension/font matrix.
